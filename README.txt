JOY'S VOYAGES — COORG LANDING PAGE

FILES
- index.html: page structure and content
- styles.css: responsive styling
- script.js: mobile navigation, enquiry form and WhatsApp actions

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Internet is required for Google Fonts and the remote Unsplash photos.

IMPORTANT — SET YOUR WHATSAPP NUMBER
1. Open script.js in a text editor.
2. Find: const WHATSAPP_NUMBER = "91XXXXXXXXXX";
3. Replace it with your WhatsApp number including country code, digits only.
   Example: 919876543210
4. Save the file and test the enquiry form.

DEPLOY TO NETLIFY
1. Go to https://app.netlify.com/drop
2. Drag and drop the extracted folder (the folder containing index.html).
3. Netlify will publish the static landing page and provide a preview URL.

NOTES
- This is a static landing page; it does not include a booking engine or database.
- Enquiry details are sent to WhatsApp only after the visitor presses Send in WhatsApp.
- Replace the sample/remote photos with your own property photos when ready.
