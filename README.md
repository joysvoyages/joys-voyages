# Joy's Voyages Landing Page

A free, responsive static landing page for Joy's Voyages.

## Files
- index.html
- style.css
- script.js

## Before publishing
1. Open `script.js`.
2. Replace `919XXXXXXXXX` with the Joy's Voyages WhatsApp number in international format.
3. Replace the sample hotel names/prices with your real properties.
4. Replace the sample image URLs with your preferred hotel/property images.

## Free hosting
This is a static website and can be hosted for free on GitHub Pages or Cloudflare Pages.
Your existing domain can be connected to the host.

## Booking
The current demo sends booking/search enquiries to WhatsApp. A Google Form + Google Sheet can be added later if you want a structured lead database.
